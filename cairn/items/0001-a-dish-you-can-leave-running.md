The apparatus exists and a culture evolves in it. It is not yet an instrument:
a run cannot be measured beyond a population count, cannot be frozen and
replayed, cannot be repeated twelve times side by side, and would run up an
unbounded API bill if left over a weekend.

This milestone turns the dish into something you can inoculate on Friday and
read on Monday. Everything in it is bookkeeping around what already works —
nothing here changes the biology. See CONCEPT.md, "What a run produces".

Done when: a dish has run unattended for 48 hours within a set budget, its
growth and diversity curves plot, a strain from hour 3 can be revived into a
fresh dish, and three replicate flasks of the same seed can be compared.
